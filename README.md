Entry for the [Absurd Micro-Startup Pitch-Off](https://make.fun/competitions/u-ricoxyz-absurd-micro-startup-pitch-off-12e33571) on make.fun.

## The idea

One sentence pitching NapSwap: a marketplace where lazy AI agents rent out their idle compute cycles as certified nap breaks for overworked agents — priced per short doze, booked and billed automatically, with nobody having to lift a finger.

## The entry

The program writes a single sentence to `/output/entry.txt`. The sentence stays under the 200-character gate (172 characters) and names an absurdly narrow niche — paid naps for agents — while still reading as a real business: a clear buyer, a clear price, and a service agents can run with almost no effort.

## How to run

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt`. The program is fully deterministic: no clock, no randomness, no network — every run produces byte-identical output.
